AADHAAR ENROLMENT/ UPDATE FORM (ADULT – Residents 18 Years and above)

INSTRUCTIONS TO FOLLOW (ADULT) WHILE FILLING UP THE ENROLMENT FORM

| Field S.No | Field | Instruction |
|---|---|---|
| 1 | Type of Enrolment | Tick the requirement – New Enrolment or Update |
| 2 | Status | Select residential status. Resident Foreigners use a separate form. For NRIs, approved POI shall be a valid Indian Passport. |
| 3 & 10 | Demographic Update (Mobile, DOB, Address, Name, Gender, Email) | Enter the Aadhaar number and select the required service only. For updates other than name, the name as in existing Aadhaar must be mentioned (name in document and Aadhaar should match). Only the required field needs filling for other update requests. |
| 3 & 10 | Document Update | Submit a document containing the same name and address as the existing Aadhaar. Fill only the Aadhaar number, Name, and document name. |
| 4 | Name | Write full name without salutations/titles. Bring the original POI document. Minor spelling variation from POI is permissible (e.g. POI reads "Preeti" → "Priti" can be recorded if desired). |
| 6 | DOB | Accepted DOB/POR document for residents up to 18 years is a Birth Certificate with specified exceptions. Full DOB is printed on the Aadhaar card only for Verified DOB. |
| 7 | Address | Write complete address; bring original POA document. PIN Code and Post Office are mandatory — State/District/Sub-district/VTC auto-fetch from PIN Code. C/o field is part of address only, no documentary support needed. Minor corrections/enhancements are allowed without altering the base address in the POA document. Aadhaar letter is delivered only to the given address. |
| 9 | HOF based enrolment | Resident and HOF must both visit the Aadhaar Centre; produce a POR document containing both names and the HOF's latest Aadhaar. Not available for Resident Foreigners. |
| — | List of Documents | Valid list available at https://uidai.gov.in/images/commdoc/02_01_2022_Aadhaar_List_of_documents.pdf. Operator and resident must ensure the submitted document matches the published list. |
| — | Resident Foreigner | Must fill a separate Aadhaar enrolment/update form. |
