# Aadhaar Enrolment & Update — Form Variants (Official Index)

Source: UIDAI, "Enrolment & Updates"
https://uidai.gov.in/hi/enrolment-and-updates

UIDAI publishes one combined Enrolment/Update form per applicant category
(the same form is used for both a brand-new application and a correction/
update — a checkbox at the top of the form selects which). The categories
are age- and residency-based:

| Applicant category | Notes |
|---|---|
| Resident Indian or NRI with Indian address proof, 18+ | Standard adult form |
| Resident Indian or NRI with Indian address proof, 5–17 | Child form |
| Resident Indian or NRI with Indian address proof, under 5 | Requires HoF (Head of Family) linkage |
| NRI with address proof outside India, 18+ | |
| NRI with address proof outside India, 5–17 | |
| NRI with address proof outside India, under 5 | |
| Resident Foreign National, 18+ | |
| Resident Foreign National, under 18 | |

For FormSaathi's purposes, the general adult resident form
(`ENROLMENT-UPDATE_Form_Adult_update_V3.pdf`) covers the large majority of
real-world users. The other variants above matter mainly for NRIs, minors,
and foreign nationals — worth supporting later if the user base needs it,
but not required for an MVP.
